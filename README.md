# Student Performance Analysis 📊

A beginner-friendly data analysis project built with **Python, Pandas, and Matplotlib** to analyze student marks, attendance, age, department, and overall performance.

## 📌 Project Overview

This project analyzes a small student dataset and generates different statistical insights and visualizations.

The project demonstrates how **Pandas** can be used for data manipulation and how **Matplotlib** can be used to create meaningful visualizations.

## 🚀 Features

- Calculate total number of students
- Calculate average, highest, and lowest marks
- Calculate average attendance
- Analyze department-wise student distribution
- Calculate department-wise average marks
- Visualize marks using a histogram
- Analyze marks vs attendance using a scatter plot
- Classify students based on their marks
- Visualize performance distribution using a pie chart
- Create a 2×2 Student Performance Dashboard

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **Matplotlib**

## 📊 Performance Classification

Students are classified based on their marks:

| Marks | Performance |
|---|---|
| < 60 | Poor |
| 60–69 | Average |
| 70–79 | Good |
| 80–89 | Very Good |
| 90+ | Excellent |

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/codewithdars/student_performance_analysis.git
```

Move into the project directory:

```bash
cd student_performance_analysis
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

```bash
python stu_perf_analysis.py
```

The program will display the analysis results and generate the visualizations.
